# EventSphere — Event Management Platform

EventSphere is a comprehensive MERN-stack event management platform tailored for Expos and Conferences. It features three distinct interfaces: Admin Panel, Exhibitor Portal, and Attendee Interface, all built with React, Node.js, Express, and MongoDB.

##  Features at a Glance

- **Admin Dashboard:** Full CRUD management for Expos, Sessions, Booths, and Applications. Real-time analytics, user management, and application reviews.
- **Exhibitor Portal:** Dedicated portal for exhibitors to manage company profiles (with Cloudinary image uploads), apply for booths, track application status, and view neighboring exhibitors.
- **Attendee Interface:** Public discovery portal for browsing upcoming expos, exploring exhibitor profiles, registering for sessions, and bookmarking events.
- **Real-Time Synchronisation:** State synchronization between the MongoDB backend and React frontend.
- **Responsive Design:** Clean, modern, and fully responsive layouts across all portals.

##  Core Technologies

- **Frontend:** React, Vite, CSS Modules / Inline Styles
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcryptjs
- **File Uploads:** Multer, Cloudinary
